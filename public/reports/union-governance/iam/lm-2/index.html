Financial filings, their provenance and the limits of the copies available for review.

Reviewed November 11, 2026

IAM International: FY2023 and FY2024

LM-2 reports describe receipts, disbursements, assets, liabilities and detailed financial schedules. These International-wide records should be read with the Financial Transparency & LM Reporting analysis, which distinguishes institution-wide figures from carrier-specific service costs.

  • FY2023 preserved copy — incomplete, 156 pages: CrewSignal's original IAM FY2023 LM-2 PDF. It contains Statements A/B and the cited District 142 block but stops mid-payee in Schedule 18. Later schedules and Item 69 are absent. Its original URL and file remain preserved.
  • FY2023 complete core reproduction — 273 pages: Wabtec-hosted IAM LM-2 reproduction. The core form extends through Item 69; separately referenced attachments were not acquired. This is an employer-hosted reproduction of the form, not a direct OLMS download. The reproduced filing, rather than the host's commentary, supplies the financial evidence.
  • FY2023 official record: OLMS report 888147, file 000-107, January 1–December 31, 2023.
  • FY2024 complete core reproduction — 155 pages: Greenville Facts-hosted IAM LM-2 reproduction, file 000-107, January 1–December 31, 2024. Item 69 is included; separately referenced constitutional attachments and latest amendment history remain unverified. An OLMS report ID for this copy has not been established.

Coverage Limits

Full International and District 142 FY2025 LM-2/990 filings, a full District 142 FY2023 LM-2 body and current amendment histories were not located in this bounded review. That is a retrieval limitation, not evidence that reports were not filed. The coverage table distinguishes the available sources and missing periods.

Previously published Local 2339N FY2024/25 observations remain visible as historical values that were not reverified here. Partial copies, indexed text, full core reproductions and complete returns are identified separately so that a source limit does not become a financial conclusion.
